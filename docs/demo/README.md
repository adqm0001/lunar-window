# Demo images

Application screenshots were captured from main `e103f29` using Chromium at 1600 × 900 and 390 × 844. The selected time is November 15, 2026, 17:00 UTC. No application page errors occurred during capture. The finder example searched the 102,400-cell polar field with a 14-day mission, 50-hour maximum night, 50% minimum flat ground and Balanced priority.

`overview`, `horizon`, `finder`, `comparison`, `landing-dates`, `sunlight`, `validation`, `phone` and `terrain` are captures of computed application output. `slide-01` through `slide-07` are rendered previews of the accompanying deck. The presentation credits SI assistance in its notes and metadata. Data and media credits are in [sources.md](../sources.md).
